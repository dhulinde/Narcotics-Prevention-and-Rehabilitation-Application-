# Project NARA 
NARA - Narcotics Addiction Recovery Application - is a SUD treatment mobile application, built to assist those on their journey to recover from substance addiction. 
Access the marketing page here: https://www.naralk.info

## Key Features
- ASSIST-backed screening test
- Personalised treatment plans
- Milestone Celebration
- 24/7 AI Chatbot
- Educational Resource Library
- Drug Alert System
